# Crypto Tracker

Telegram-бот публикует рынок в двух режимах: минутная лента с компактной таблицей или одна обновляемая карточка. Он также отвечает на команды в чатах, где получает сообщения.

## Команды

- `/market` - текущие котировки.
- `/price BTC` - подробная карточка монеты.
- `/chart TON` - график цены за 24 часа.
- `/watch BTC TON SOL` - сохранить личный список наблюдения.
- `/watch` - показать свой список.
- `/alert BTC > 100000` - добавить личный ценовой алерт.
- `/alerts` - показать активные личные алерты.

## Настройка

Скопируйте `.env.example` в `.env` только на сервере и заполните токен с ID целевого канала. `.env` намеренно исключён из Git.

`UPDATE_INTERVAL_SECONDS` задаёт частоту публикаций. `PUBLISH_MODE=feed` создаёт новую таблицу каждое обновление, `PUBLISH_MODE=dashboard` редактирует одну живую карточку. `MOVE_ALERT_PERCENT` и `ALERT_COOLDOWN_MINUTES` управляют общими уведомлениями о резких движениях рынка.

## Данные

Котировки поступают из CoinGecko. Бот не является торговым советником и не запрашивает приватные ключи или seed-фразы.
